# Reflection on Using Claude Code AI Assistance

**AI platform and model:** Claude Code (cloud session at claude.ai/code), model Claude Opus 5.5 (`claude-opus-5-5`)

## About AI as a tool

What surprised you most about using AI for coding?
- How AI can also teach you coding while you develop products to be used by students and professionals.

When was AI most helpful? Least helpful?
- AI was helpful throughout the entire project, including the exercises within this course.

How did using AI change your development process compared with IA 2, where AI-generated code was prohibited?
- I had to relearn some things and understand the changes that were necessary in IA 2. Setting up a serverless project helped me understand how technology has evolved from hardware network infrastructure to serverless cloud infrastructure.

What skills did you need that AI couldn't provide?
- The human touch; AI won't ever replace that. Following the exercise guide made it possible for me to build, verify, and publish (push) the complete project.

How did you break the project down into AI prompts?
- Initially, I asked AI to develop a landing page as required for my portfolio, and I used the bullet points from the IA 3 guide.
- Next, I asked AI to create sub-pages that describe me, list my projects, identify my skills, and provide a contact page. I asked it to link them all together and make the site easy to use, professional, and inviting so employers would want to hire me.

Did your prompting strategy change as you worked? How?
- Yes, because of errors that had to be fixed and updated while creating the build in Cloud Run and GitHub.

How did you judge whether AI-generated code was good?
- I read the code in the server folder to verify it and checked the data. If there was anything I did not like, I edited the code myself.

What would you do differently on your next AI-assisted project?
- Have a detailed plan and a complete prompt describing how I want AI to create my project and help me make it professional.

## About professional development

How does this experience change your view of software development as a career?
- This changes what I consider normal for infrastructure. However, if there is no network connection or power for AI to run a project, AI would not be able to run on any platform without human interaction.

What does "knowing how to code" mean in an AI-assisted world?
- It means you cannot trust AI for everything, because AI does make mistakes or doesn't give the correct output that the human needs.

How will you use AI tools in future projects or internships?
- The same way I am learning to use them in this DevOps course, especially for project management initiatives with future employers.

What parts of development do you think AI won't replace?
- The core network infrastructure. You will still need hardware for those who want to maintain and own their own infrastructure. Will this become obsolete in the future? Only if big data corporations own all the infrastructure and require subscriptions and contracts for serverless environments for companies to run on.
